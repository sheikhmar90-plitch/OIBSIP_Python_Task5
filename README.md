# Task 5 - Python Chat Application

## Objective
To develop a simple Python chat application using socket programming, with separate server and client modules.

## Tools Used
- Python
- socket library
- VS Code (or any IDE)

## Steps Performed
1. Created a server module (`server.py`) to manage connections.
2. Created a client module (`client.py`) to connect to the server.
3. Tested communication between multiple clients.
4. Ensured messages are sent and received in real-time.

## Outcome
The project demonstrates basic networking concepts and allows users to communicate through a Python-based chat application.
